# Решение задач из курса осеннего практикума для студентов 4-го курса кафедры Алгоритмических языков ВМК МГУ
**Язык программирования: Prolog**

Привет! В этом репозитории собраны решения домашних заданий практикума, а также основная информация о том, как устроен курс

> *Если вас интересует проектное большое задание, перейдите в следующий репозиторий: [Prolog Course Scheduler](https://github.com/ovladisluvv/prolog-course-scheduler)*

## Структура курса:
*Получение условий и сдача кода проходят лично с преподавателем*

2 домашних задания: 
- Небольшое задание 1, направленное на реализацию нескольких из 20 несложных алгоритмов, с дополнительными задачами во время сдачи
- Большое задание 2, направленное на реализацию многофункционального приложения, с реализацией дополнительных возможностей во время сдачи
  - К реализации задания 2 необходимо подготовить развернутый отчет по выполненной работе 

*Важно учитывать: варианты заданий для каждого студента индивидуальные, на выбор варианта предоставляется время*

## Система оценивания:
- После каждого занятия студентам предлагается написать самостоятельную работу, что также позволяет отслеживать посещаемость
  - Оценки за самостоятельные суммируются в единую оценку
  - При получении высокого балла за самостоятельные работы, оценка за контрольную работу выставляется автоматом
- Общая оценка по курсу складывается из 4 частей:
  - Самостоятельные работы
  - Контрольная работа
  - Задание 1
  - Задание 2
- Поздняя сдача заданий дедлайна постепенно снижает получаемую оценку за курс вплоть до **Удовлетворительно**. Старайтесь сдавать задачи как можно раньше!
  
## Структура репозитория:

Задания из курса разбиты по папкам согласно следующему шаблону:
```text
    ├── task1
    │ ├── task1_1.pl
    | |   ...
    | ├── task1_20.pl
    │ └── prolog1_26.pdf
    |
    ├── task2
    │ └── prolog2_26.pdf
    |
    ├── report_scheduler
    │ ├── report_scheduler.pdf
    │ └── report_scheduler.tex
```
где prologN_26.pdf - условие задания N, report_scheduler.pdf - готовый отчет, report_scheduler.tex - исходный LaTeX-код отчета
